# Capper Day
Страница: https://kenlampnn-prog.github.io/capper-day/

## Telegram CTA (не удалять при ежедневном обновлении)
В `index.html` есть кнопка `a.tgbtn` в шапке (рядом с лампой темы) и блок `aside#tgcta` перед `<script>`. Обе ссылки ведут на https://t.me/capperday. Ежедневное обновление меняет только данные; эти элементы и их CSS (`.tgbtn`, `.tgcta`) нужно сохранять.

## Бренд (не откатывать)
`<title>`, `og:title` и `twitter:title` = «Capper Day — купон КХЛ/НХЛ». В `manifest.json`: name «Capper Day — купон КХЛ/НХЛ», short_name «Capper Day». В шапке написано `CAPPER <b>DAY</b>` (класс `.brand`). Ежедневная рутина должна оставлять это как есть и не возвращать «KHL Bet». Название Telegram-канала: «Capper Day | Ставки КХЛ НХЛ, купон дня».

### Стиль (с 20.10.2026): мягкий мультяшный 3D, БЕЗ НЕОНА
- Тёплая светлая палитра: небесно-голубой `#3c9be6`, тёплый оранжевый `#ff8b3d`, кремовый `#fdf5e8`, ледяной белый, мягкий красный `#e2564b`, зелёный «плюс» `#2aa866`.
- Шрифты Google Fonts: Nunito (основной, кириллица) и Baloo 2 (только латинские `CAPPER DAY` и крупные цифры банка).
- «Глиняные» карточки: радиус 28–30px, мягкие тени (`--clay`, `--clay-sm`), без размытого стекла.
- Шапка `.hero`: небо с облаками и ледяной холм, маскот `mascot-hero.webp` (3D-шайба в шлеме с клюшкой, круглый бейдж с белой рамкой; как аватар канала). Старый SVG-маскот `mascot.svg`/`mascot.png` остаётся для карточки купона. Иконки приложения: `favicon.ico`, `favicon-16/32.png`, `apple-touch-icon.png`, `icon-192/512.png`, `icon-maskable-512.png` (ссылки с `?v=3`).
- Лампа `.lamp` (💡): мягкая мультяшная кнопка без свечения. Она переключает `body.light` на тёплый «вечерний» вариант палитры.
- **НЕОН ЗАПРЕЩЁН:** никаких `text-shadow`, свечений (`box-shadow 0 0 …`), неоновых цветов (`#00f0ff`, `#b14bff`, `#3dffa8`, `#ff4d7d`), тёмных киберпанк-фонов, светящихся рамок и `drop-shadow` glow. Не используем персонажей, логотипы и название чужих студий.
- Ежедневная рутина меняет только данные (карточки, банк, итоги, архивы) и не трогает блок `<style>`, `<link>` шрифтов, `.hero`, маскота, `.tgbtn` и `#tgcta`. Новые элементы добавляем только с существующими классами.
- Карточка купона для Telegram: `tools/tg_post.py` рисует её в том же стиле (кремовая клей-карточка на фоне неба, маскот, одинары голубым, экспресс оранжевым, банк зелёным, бейдж 18+ мягким красным). Не возвращать старый неоновый рендер.

### Логотипы команд (обязательно)
- Все логотипы лежат в репозитории: `logos/khl/` (24 клуба КХЛ 2026/27, img.khl.ru), `logos/nhl/` (32, assets.nhle.com), `logos/del/` (14, penny-del.org), `logos/nor/` (16 Элитсерия + 16 OBOS, eliteserien.no / obos-ligaen.no). PNG 96×96, прозрачный фон. Хотлинк запрещён.
- `logos/map.json`: название команды как на сайте (плюс русские и латинские варианты) → файл. **Ежедневная рутина обязана использовать `logos/map.json` для каждой команды.**
- После обновления `index.html` запускать `python3 tools/apply_logos.py`. Скрипт превращает буквенные кружки `.av` в белые скруглённые бейджи `.av.logo` с `<img alt="Команда">`. Если команды нет в карте, он печатает `MISSING …` и оставляет буквенный кружок.
- На каждый `MISSING` нужно скачать логотип с официального сайта лиги (khl.ru, nhl.com, penny-del.org, eliteserien.no или obos-ligaen.no), уменьшить до 96×96 PNG, положить в `logos/<лига>/`, добавить ключ в `map.json` и перезапустить скрипт. Нельзя брать логотипы с неофициальных сайтов, нельзя рисовать их самому, нельзя ставить хотлинк. Khl.ru блокирует частые запросы, поэтому качать по одному файлу.
- Карточка купона в Telegram (`tools/tg_post.py`) тоже берёт логотипы из `logos/map.json`: оба клуба у каждого одинара и у каждой ноги экспресса, в белых бейджах с мягкой тенью.
