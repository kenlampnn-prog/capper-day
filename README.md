## Ставка и правила купона (с 24.10.2026)
- **Фикс 200 ₽ на каждую ставку с купона 24.10.2026** (решение автора, подтверждено 24.10 до начала матчей). История: 12.10 — 200; 13–15.10 — 1000; 16–18.10 — 200; 19–20.10 — 1000; 21–23.10 — 500; с 24.10 — 200. Каждый день рассчитывается по той ставке, по которой он был поставлен. Менять ставку после начала первого матча дня нельзя; до начала — только `python3 tools/ledger.py restake ДАТА --stake N` (старый отпечаток остаётся в истории `hashes.txt`). Банк продолжается с текущей страницы (утро 24.10 — 6 298 ₽), не сбрасывается.
- **Купон: максимум 2 одиночки + максимум 1 экспресс с общим кэфом от 3.00.** Ноги экспресса — каждая от 1.70, из разных матчей; одиночка в экспрессе не повторяется.
- Кэф **от 1.70** для каждой ставки и ноги (футбол — от 1.80), кэф — из названной БК/источника, перепроверен перед публикацией; только реальные матчи, которые ещё не начались (сегодня и ночь по МСК).
- Лиги купона: КХЛ, НХЛ, DEL, футбол Норвегии (Элитсерия, OBOS и др.).
- Победа — только с подписью: «основное время» или «с ОТ и буллитами». По умолчанию КХЛ — основное время, НХЛ и DEL — с ОТ и буллитами.
- Рынки: исход, общий тотал, фора, индивидуальный тотал (колонка `market` в `data/bets.csv`). Тоталы и фора аутсайдера — не по умолчанию: только если по реальной статистике это явно лучший вариант (обоснование — в карточке и `reports/ДАТА.md`).
- Отбор: берём самые сильные ставки с реальной статистикой (форма, забито/пропущено, очные, таблица, травмы, движение линии), где наша оценка вероятности ≥ вероятности по кэфу (1/кэф). Жёсткого теста «+5 п.п.» больше нет. Нет таких ставок — ставим меньше и честно пишем об этом, купон не «добиваем».
- МХЛ и «Самые проходимые матчи дня» — справочно, в купон и банк не идут. Их пики пишутся в `data/info_picks/ДАТА.json`, наутро рассчитываются в «Итогах». Добавление в купон в течение дня — через `tools/ledger.py add-coupon --json` как дополнение (новый отпечаток, пометка «дополнение к купону HH:MM UTC, до начала матчей»).
- Прежние правила (21–23.10): фикс 500 ₽, кэф от 1.80, одиночки без лимита при тесте «оценка ≥ 1/кэф + 5 п.п. и ≥ 50%», экспресс только из 2 сильнейших.

### Логотипы команд (обязательно)
- Все логотипы лежат в репозитории: `logos/khl/` (24 клуба КХЛ 2026/27, img.khl.ru), `logos/nhl/` (32, assets.nhle.com), `logos/del/` (14, penny-del.org), `logos/nor/` (16 Элитсерия + 16 OBOS, eliteserien.no / obos-ligaen.no). PNG 96×96, прозрачный фон. Хотлинк запрещён.
- `logos/map.json`: название команды как на сайте (плюс русские и латинские варианты) → файл. **Ежедневная рутина обязана использовать `logos/map.json` для каждой команды.**
- После обновления `index.html` запускать `python3 tools/apply_logos.py`. Скрипт превращает буквенные кружки `.av` в белые скруглённые бейджи `.av.logo` с `<img alt="Команда">`. Если команды нет в карте, он печатает `MISSING …` и оставляет буквенный кружок.
- На каждый `MISSING` нужно скачать логотип с официального сайта лиги (khl.ru, nhl.com, penny-del.org, eliteserien.no или obos-ligaen.no), уменьшить до 96×96 PNG, положить в `logos/<лига>/`, добавить ключ в `map.json` и перезапустить скрипт. Нельзя брать логотипы с неофициальных сайтов, нельзя рисовать их самому, нельзя ставить хотлинк. Khl.ru блокирует частые запросы, поэтому качать по одному файлу.
- Карточка купона в Telegram (`tools/tg_post.py`) тоже берёт логотипы из `logos/map.json`: оба клуба у каждого одинара и у каждой ноги экспресса, в белых бейджах с мягкой тенью.

## Журнал ставок и статистика (обязательно)

Публичный журнал всех ставок с 12.10.2026 и страница [stats.html](https://kenlampnn-prog.github.io/capper-day/stats.html) («Статистика — Capper Day»). В `index.html` во вкладках рядом с «Банк» стоит кнопка `<a class="statbtn" href="stats.html">📊 Статистика</a>` — **не удалять при ежедневном обновлении**.

Файлы:
- `data/bets.csv` — журнал: строка на каждую одиночку, на каждый экспресс и на каждую ногу экспресса (`kind` = single | express | leg, `express_id` связывает ноги). Прибыль только у single/express. Результаты: win | loss | open | void. Ничего не удаляем, проигрыши остаются.
- `data/coupons/YYYY-MM-DD.json` — канонический купон дня (сортированные ключи, без пробелов, UTF-8): пики, кэфы, правило (осн. время / с ОТ и буллитами), ставка, `published_at`. Файл не меняется после фиксации.
- `data/coupons/hashes.txt` — строки `дата sha256 первый_коммит`. Проверка: `sha256sum data/coupons/2026-10-21.json` или `python3 tools/ledger.py verify`.
- `data/coupons/github-push-events.json` — снимок ленты событий GitHub (серверное время пушей) для бэкфилла.
- `data/site_bank.json` — банк, который сайт показывал утром каждого дня; `build` сверяет его с журналом и пишет «РАСХОЖДЕНИЕ», если не сходится. Каждое утро добавлять строку `"YYYY-MM-DD": <банк на сайте>`.
- `stats.html` — генерируется `build`, руками не править.

Доказательство «до матча»: купон фиксируется `add-coupon` и пушится вместе с утренним `index.html` (до первого матча дня); время пуша видно в истории GitHub. Купоны 12–20.10 восстановлены 21.10 из истории `index.html` — для них доказательство — коммит сайта того утра (указан в hashes.txt), а не время создания json. Скрипт бэкфилла: `tools/ledger_backfill.py`.

Банк: база 9 708 ₽ утром 12.10; банк = база + прибыль рассчитанных ставок; открытые ставки не вычитаются. ROI = прибыль / оборот. Проходимость = выигрыши / (выигрыши + проигрыши) по одиночкам и экспрессам.

Ежедневно (утренний апдейт, после расчёта результатов и до пуша):
```bash
# 1) расчёт вчерашнего купона (id: S1, S2 — одиночки; E1-L1, E1-L2 — ноги; экспресс считается сам)
python3 tools/ledger.py settle 2026-10-21 --set S1 win "3:1" --set S2 loss "1:2 ОТ" --set E1-L1 win "2:4" --set E1-L2 loss "3:2"
#    или из файла: python3 tools/ledger.py settle 2026-10-21 --json /tmp/results.json
#    формат: {"S1":{"result":"win","score":"3:1"},"E1-L2":{"result":"void","score":"перенос"}}
# 2) зафиксировать сегодняшний купон (после записи index.html; парсер берёт карточки take / «в экспресс»)
python3 tools/ledger.py add-coupon 2026-10-22            # проверь вывод: пики, кэфы, правило, ставка
#    если парсер ошибся — дать json: python3 tools/ledger.py add-coupon 2026-10-22 --json /tmp/coupon.json
#    формат json: {"stake":500,"bets":[{"kind":"single","league":"КХЛ","match":"A — B","pick":"П1 A","rule":"осн. время","odds":1.85,"odds_source":"Фонбет"},
#                  {"kind":"express","odds":4.15,"legs":[{...как single без kind...},{...}]}]}
# 3) пересобрать страницу (и проставить коммит в hashes.txt для купонов, у которых он ещё «-»)
python3 tools/ledger.py build
python3 tools/ledger.py verify
```
Купон после фиксации не перезаписывается (только `--force`, и это будет видно в git). Правило расчёта: КХЛ — только основное время; НХЛ и DEL — с ОТ и буллитами; Норвегия — 90 минут, кэф ≥ 1.80.
